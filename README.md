# Responsive Landing Page

## Overview

This project was developed as Task-01 of the Prodigy Infotech Web Development Internship.

The objective was to create a responsive landing page with an interactive navigation menu that changes style when the user scrolls or hovers over menu items.

## Features

- Fixed Navigation Bar
- Interactive Hover Effects
- Navbar Color Change on Scroll
- Smooth Scrolling Navigation
- Responsive Design
- Modern UI Layout
- Scroll-Based Animations
- Cross-Device Compatibility

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```
project-folder/
│
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Launch `index.html` in your browser.

## Internship Task

**Task-01: Responsive Landing Page**

Create an interactive navigation menu that changes color or style when scrolled or when hovering over menu items. The navigation menu should have a fixed position and be visible on all pages.
